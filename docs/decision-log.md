# 閱讀器決策紀錄

## 2026-10-28

### 實際校機工時先保留

目前先保留主系統既有的開始時間、結束時間與運作時長顯示方式。閱讀器不新增「扣除缺料／停工後的實際工時」計算，也不在本機保存或重算工時資料。

原因：目前業務經理不一定會查看這項數據，先維持簡單唯讀閱讀器，避免提前改動主系統資料模型與工時計算規則。

日後若確認需要，應先由主系統定義停工區間、重疊區間、未結束區間與缺料是否計入停工，再由主系統提供結果；閱讀器只顯示，不自行推導。

### 閱讀器定位

閱讀器是 Windows 啟動器，不是第二套報工系統。它不建立資料庫、不執行 Flask、不修改主系統資料，只開啟主系統的 `/manager` 報表專用入口。

### 主系統 `/manager` 唯讀入口

主系統已新增獨立的 GET `/manager` 頁面，直接使用既有 `inspection_order` 與 `inspection_material_pause` 資料。頁面提供訂單／機台／機型／校機人員／狀態查詢、單筆訂單明細、缺料暫停區間與既有實際校機工時顯示。

此入口只接受 GET；不提供建立、編輯、取消、刪除、列印、設定或條碼操作。閱讀器不需要重新建置即可使用這個入口，但主系統服務必須重新啟動後才會載入新路由。
